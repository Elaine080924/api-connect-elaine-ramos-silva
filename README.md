# API Connect

## Objetivo

A API Connect é uma API REST desenvolvida como um MVP para gerenciamento de usuários.

O projeto tem como objetivo demonstrar a criação de uma aplicação back-end capaz de receber requisições HTTP, processar dados no formato JSON e disponibilizar endpoints para criação e consulta de usuários.

A API também possui validações para impedir o cadastro de usuários sem informações obrigatórias e retorna códigos de status HTTP adequados para cada situação.

---

## Tecnologias utilizadas

- Node.js
- Express.js

- JSON
- Git
- GitHub

- Visual Studio Code para desenvolvimento
